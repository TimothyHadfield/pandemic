# Pandemic Lab: project rules

Read `progress.md` first (START HERE). Tim's global rules (`~/.claude/CLAUDE.md`) and the Code Projects rules apply.

- **What it is:** Pandemic (2013 second edition) to play against computer teammates or online with friends, plus a real-table infection tracker with exact odds, a planner, and measured team win rates. Static site on GitHub Pages: https://timothyhadfield.github.io/pandemic/ (repo TimothyHadfield/pandemic, public).
- **Money: $0.** No build step, no paid services. Online play uses the shared free Firebase project through `js/online.js` (copied unchanged from `Board and Card Games/_online`; never edit it here, never make another Firebase project).
- **Look:** the dark Hub tokens in `index.html :root` (bg #0f1117, card #1a1e2b, line #2a3042, text #e8eaf0, muted #969db4, accents #6ea8fe / #f0b354), system-ui. Phone: bottom tabs, no page scroll on the game screen. Laptop: top tabs, map + side panel. Our own SVG art only (no box art or rulebook text).
- **Files:** `js/data.js` board, roles, events · `js/engine.js` rules (pure, seeded, JSON state) · `js/odds.js` exact infection/epidemic odds · `js/bots.js` computer teammates + planner · `js/online-game.js` the engine as the online module's `game` · `js/art.js` map, cards, icons · `js/app.js` screens · `js/strength-data.js` measured win rates (generated) · `js/map-data.js` land + lakes (generated by `node tools/build-map.js` after `npm install`; it also writes the city x/y in `js/data.js`).
- **Tests:** `node --test tests/engine.test.js` (about 75 s) and `node tests/online.test.mjs`, plus `node tests/over-prompts.test.mjs` (WebKit, needs Playwright in `~/.claude/tools`). (`node --test tests/` does not work on Windows.) A new test must be seen failing on a broken engine first.
- **Measure the computers:** `node tools/measure.js 40` (quick table) · `node tools/build-strength.js 200` rewrites `js/strength-data.js`.
- **Online check:** `node tools/two-browsers.mjs <url>` (two headless browsers on the real project).
- **Whole game in a browser:** add `?autoplay` to the URL and the computer plays your seat too (test hook).
- Bump the `?v=` numbers on the script tags in `index.html` when JS changes, so phones get the new files.
